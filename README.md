# MellShop — магазин мягких игрушек

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Дисциплина: «Фронтенд и бэкенд разработка».

## Описание

MellShop — многостраничный HTML/CSS-сайт магазина мягких игрушек: герои игр, мемов и мультфильмов и классические мягкие зверята. На сайте есть главная страница, каталог с фильтрами, страница товара с таблицей характеристик, страница оформления заказа и контакты.

Проект выполнен без CSS-фреймворков. JavaScript используется только для модального окна заявки на главной странице.

## Структура проекта

- `index.html` — главная страница: первый экран, преимущества, популярные товары, блок с подарком, модальное окно заявки;
- `catalog.html` — каталог: фильтры и 7 карточек товаров;
- `product.html` — страница товара «Бенгальский кот»: фото, описание, цена, таблица характеристик;
- `order.html` — оформление заказа: форма с группами полей и способом доставки;
- `contacts.html` — контактная информация и ссылка на форму заказа;
- `css/style.css` — файл стилей;
- `js/main.js` — открытие модального окна и обработка формы заявки;
- `images/` — фотографии товаров, картинка первого экрана и превью для соцсетей;
- `sitemap.xml` — карта сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Реализованные требования КР №1

- **Пять страниц** с уникальными `title` и `meta description`, общей навигацией и общим CSS-файлом.
- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- **Навигация:** единое меню, якорные ссылки, хлебные крошки на внутренних страницах.
- **Карточки товаров:** блок `product-card`, сетка через CSS Grid.
- **Таблица** характеристик на `product.html`: `caption`, `thead`, `tbody`, `th`, `td`.
- **Формы:** модальное окно `<dialog>` на главной и отдельная страница заказа `order.html`.
- **CSS:** переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`.
- **Flex/Grid:** меню и карточки (Flexbox), сетка товаров, каталог «фильтры + товары» и страница товара (Grid).
- **Позиционирование:**
  - `position: relative` — карточка товара;
  - `position: absolute` — бейдж «Хит / Новинка / Скидка» в углу фото;
  - `position: sticky` — панель фильтров в каталоге;
  - `position: fixed` — кнопка «↑ Наверх»;
  - `z-index` — бейдж поверх фото, кнопка «Наверх» поверх всего содержимого.
- **БЭМ:** все компоненты оформлены как блоки, элементы и модификаторы.

## Самостоятельные доработки

Сверх пошаговых методических указаний в проекте сделано:

1. **Своя тема магазина.** Вместо учебных «Товар 1/2/3» — магазин мягких игрушек MellShop: 7 товаров с фотографиями, описаниями, ценами и категориями.
2. **Собственное визуальное оформление.** Тёплая жёлто-фиолетовая палитра (меняется в одном месте — в CSS-переменных `:root`), шрифт Nunito, увеличенные скругления, картинка магазина игрушек в первом экране под полупрозрачным слоем.
3. **Улучшенные карточки товаров.** Фото, категория, бейджи «Хит», «Новинка», «Скидка» через БЭМ-модификаторы (`product-card__badge--new`, `--sale`), зачёркнутая старая цена (`<s>`), карточка со скидкой (`product-card--discount`), подъём с тенью при наведении (`transform`, `box-shadow`, `transition`).
4. **Страница товара.** Двухколоночная раскладка через Grid и таблица характеристик с чередованием цвета строк (`:nth-child(even)`).
5. **Доработанная форма заказа.** Группы полей через `fieldset`/`legend`, выбор товара, способ доставки (radio), кнопка «Очистить форму» (`type="reset"`), проверка полей встроенными средствами браузера.
6. **Навигация.** Трёхуровневые хлебные крошки «Главная / Каталог / Товар», «липкие» фильтры каталога, кнопка «↑ Наверх» с плавной прокруткой, меню без дублирующих пунктов.
7. **Доступность.** Ссылка «Перейти к содержимому» для пользователей клавиатуры (появляется по Tab), `aria-current="page"` у текущей страницы в меню и хлебных крошках, `alt` у всех изображений, `label` у всех полей, видимый фокус, контраст текста не ниже 4,5:1.
8. **Аккуратный БЭМ.** Компоненты стилизуются через классы, стилей через `id` нет; селекторы по тегам остались только в базовых стилях (`body`, `a`) и в таблице характеристик. Исправлен баг, из-за которого при наведении текст ссылок-кнопок сливался с фоном.
9. **Open Graph и карта сайта.** Превью ссылки в мессенджерах и `sitemap.xml` со всеми страницами.

## БЭМ-структура проекта

- `site-header` — шапка сайта;
- `site-nav` — основная навигация (модификатор `site-nav__link--active`);
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (модификаторы `--featured`, `--discount`);
- `product` — блок товара на странице `product.html`;
- `product-table` — таблица характеристик;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters`, `filters-form` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки (модификатор `--page` для страницы заказа);
- `button` — кнопка (модификаторы `--primary`, `--secondary`, `--disabled`);
- `to-top` — кнопка «Наверх»;
- `skip-link` — ссылка «Перейти к содержимому»;
- `site-footer` — подвал сайта.
